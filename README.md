# Тетрис

Классический Тетрис в двух вариантах: на Python (pygame) и на Java (Swing).
Код простой, с комментариями на русском — писался как учебный проект.

## Запуск

**Python** (нужен Python 3 и библиотека pygame):

```
pip3 install pygame-ce
python3 tetris.py
```

**Java** (нужен JDK 11 или новее):

```
java Tetris.java
```

## Управление

| Клавиша | Действие |
|---|---|
| ← → | двигать фигуру |
| ↑ | повернуть |
| ↓ | опустить на клетку быстрее |
| пробел | уронить сразу вниз |

За каждую собранную строку даётся 100 очков.
